## 🍽️ Recipe Finder 👩‍🍳

A simple web application that lets users search for recipes using TheMealDB API. Users can search meals by name or keyword, view results, and explore detailed instructions, ingredients, and even YouTube tutorials.

----------------------

##  Features 🚀

- 🔍 Search meals by keyword

- 🖼️ Display meal cards with images and categories

- 📖 View detailed recipe instructions

- 🧾 Ingredient list with measures

- 🎥 YouTube video link for cooking tutorials

- 📱 Responsive design for mobile and desktop

--------------------------------

## Technology 🛠️
 1. HTML5
 2. CSS3 (custom styling with variables, responsive grid)
 3. JavaScript (ES6+)
 4. TheMealDB API
